1. **Factory:** Creación centralizada de productos en el catálogo.
2. **Facade:** Encapsulamiento del proceso de checkout en una única interfaz simple.
3. **Chain of Responsibility:** Validación en cadena de una compra (usuario -> stock -> pago).
4. **Circuit Breaker:** Manejo de fallos en servicios externos.
5. **Adapter:** Integración con múltiples pasarelas de pago (Yape, Plin, Tarjeta).
6. **CORS:** Configuración de origen cruzado entre Angular y Express.
