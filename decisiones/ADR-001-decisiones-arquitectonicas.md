# Registros de Decisiones Arquitectónicas (ADR)

Este documento registra las decisiones arquitectónicas clave adoptadas para el **Sistema Web Integral de Licencias de Conducir Clase B en Huamanga**, respondiendo a los drivers arquitectónicos y restricciones del negocio.

| ID | Decisión Arquitectónica | Driver Relacionado | Justificación | Resultado / Impacto |
| :--- | :--- | :--- | :--- | :--- |
| **ADR-001** | **Monolito Modular** | DA01 (Independencia), DA04 (Bajo costo y escalabilidad) | Organizar las funcionalidades en módulos claramente definidos (*Identidad*, *Orientación*, *Checklist*, *Agenda*, *Simulacros*, *Seguimiento*) dentro de un único despliegue simplifica la operación y reduce costos iniciales. | Aplicación cohesiva, bajo costo operativo y facilitación de un despliegue sencillo en Render/Docker. |
| **ADR-002** | **Clean Architecture (Arquitectura Limpia)** | DA01 (Adaptabilidad), DA02 (Privacidad), DA04 (Mantenibilidad) | Desacoplar las reglas del negocio de los frameworks, bases de datos y servicios externos. Permite probar la lógica del dominio sin depender de sistemas de la municipalidad. | Dominio aislado e independiente de tecnologías externas; facilita pruebas unitarias y cambios futuros. |
| **ADR-003** | **Integración de Servicios mediante Puertos y Adaptadores (Arquitectura Hexagonal)** | DA01 (Desacoplamiento), DA02 (Aislamiento oficial) | Permite conectar proveedores de correo (SMTP), notificaciones (Web Push) o mapas (OpenStreetMap) usando adaptadores. Mantiene simuladas (Mocks) las integraciones con RENIEC o MTC hasta tener autorización oficial. | Cero acoplamiento con API oficiales no autorizadas; sustitución rápida de adaptadores de infraestructura. |
| **ADR-004** | **Estrategia de Almacenamiento Seguro de Documentos (MinIO / S3 con URLs temporales)** | DA02 (Protección de datos) | Resguardar los documentos privados cargados por el ciudadano sin exponer la base de datos ni los archivos al público general. | Acceso a archivos personales mediante URLs firmadas de tiempo limitado, garantizando privacidad y cumplimiento de RNF-02. |
| **ADR-005** | **Estrategia de Caché de Consultas Frecuentes (Redis)** | DA03 (Rendimiento) | Optimizar el tiempo de respuesta en la consulta de categorías, listas de requisitos estáticos y preguntas frecuentes de simulacros. | Respuestas de lectura en menos de 3 segundos (RNF-05) y menor carga sobre PostgreSQL. |
