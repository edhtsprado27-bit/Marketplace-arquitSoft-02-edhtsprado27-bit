# Actores del Sistema

Los actores son personas, organizaciones o sistemas externos que interactúan con el Marketplace para realizar una acción o intercambiar información.

| Actor | Tipo | ¿Qué necesita realizar? |
| :--- | :--- | :--- |
| **Cliente** | Humano | Buscar productos, consultar información, agregar productos al carrito, realizar pedidos, efectuar el pago y consultar el estado de sus pedidos. |
| **Seller** | Humano | Ofrecer productos, registrar productos, actualizar productos, consultar sus productos y gestionar la información relacionada con sus ventas. |
| **Administrador** | Humano | Administrar la plataforma, gestionar cuentas de sellers y monitorear la operación general del sistema. |
| **Pasarela de Pago** | Sistema Externo | Procesar las transacciones financieras y validar los pagos de los pedidos. |
| **Servicio de Envío** | Sistema Externo | Gestionar y proporcionar información sobre la logística y estado de entrega de los productos. |
| **Servicio de Facturación** | Sistema Externo | Generar y emitir comprobantes de pago electrónicos de manera automatizada. |
| **ERP** | Sistema Externo | Proporcionar e integrar la información de productos, inventario y stock centralizado. |
