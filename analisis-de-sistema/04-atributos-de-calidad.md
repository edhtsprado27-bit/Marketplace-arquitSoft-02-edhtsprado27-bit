# Atributos de Calidad

Definen las características no funcionales del sistema para evaluar cómo debe comportarse ante escenarios exigentes como campañas comerciales de alta demanda.

| ID | Atributo de Calidad | Escenario de Calidad |
| :--- | :--- | :--- |
| **AC01** | **Rendimiento** | Las consultas de productos y operaciones del carrito deben responder en menos de 2 segundos incluso ante un incremento de tráfico concurrente. |
| **AC02** | **Disponibilidad** | El sistema debe permanecer disponible el 99.5% del tiempo durante campañas comerciales permitiendo transacciones sin interrupciones. |
| **AC03** | **Escalabilidad** | El sistema debe soportar un incremento sustancial en el volumen de usuarios y peticiones activas sin degradar su desempeño general. |
| **AC04** | **Seguridad** | Los datos de los usuarios, credenciales y transacciones de compra deben transmitirse encriptados y protegidos contra accesos no autorizados. |
| **AC05** | **Mantenibilidad** | El sistema debe organizarse mediante un diseño desacoplado que facilite modificar módulos específicos sin afectar otras funcionalidades. |
